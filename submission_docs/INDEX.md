# G4 Week 2 AgentForge – Submission Documents

This folder contains the required deliverables for the G4 Week 2 (Building Production-Ready Domain-Specific AI Agents) submission.

| Document | Description |
|----------|-------------|
| **README.md** (repo root copy) | Setup guide, quick start, deployed link. |
| **ARCHITECTURE.md** | Agent architecture (domain, framework, tools, verification, observability). |
| **G4_WEEK2_AUDIT.md** | Requirements audit vs PDF; MVP, tools, evals, observability, verification, cost, open source. |
| **COST_ANALYSIS.md** | AI cost analysis: dev spend, per-query breakdown, 100/1K/10K/100K user projections. |
| **PRE-SEARCH.md** | Pre-Search phases 1–3 (domain, framework, failure modes, security, testing, deployment). |
| **mvp_evals.json** | Eval dataset (75 cases): correctness, tool selection, tool execution, edge cases, adversarial, multi-step. |
| **eval_results_sample.json** | Sample eval run results (pass rates, latency, category breakdown). |
